# خودرو من | Peugeot 206 Care

دفترچه‌ی نگهداری پژو ۲۰۶ برای اندروید؛ فارسی، راست‌چین، موبایل‌محور و قابل استفاده بدون اینترنت.

## امکانات
- داشبورد با کیلومتر فعلی، هزینه‌ها، تعداد سرویس‌ها و موعدهای نزدیک
- مشخصات خودرو: تیپ، سال، موتور، رنگ، پلاک، شاسی و کیلومترشمار
- ثبت و ویرایش سوابق سرویس و تعمیرات با دسته‌بندی، تاریخ، کیلومتر، هزینه، قطعه/برند و موعد بعدی
- دفترچه قطعات: نام قطعه، دسته‌بندی، برند/کد، وضعیت نصب یا تعویض، هزینه و موعد تعویض
- ثبت سوخت‌گیری: لیتر، مبلغ، نوع سوخت، کیلومتر و محاسبه‌ی تقریبی مصرف با داده‌های کافی
- ثبت جداگانه‌ی کیلومترشمار
- دفتر هزینه‌ها با دسته‌بندی و گزارش خلاصه
- تم روشن و تیره، رابط واکنش‌گرا برای گوشی و صفحه بزرگ
- ذخیره‌سازی محلی، خروجی JSON و بازیابی پشتیبان
- یادآوری روزانه‌ی اندروید با انتخاب ساعت؛ برای اعلان‌ها باید مجوز اندروید داده شود
- بدون حساب کاربری و بدون نیاز به اینترنت برای استفاده‌ی روزمره

## ساخت APK
1. وارد بخش Actions شو: https://github.com/canfigvpn/app/actions
2. اجرای **Build Android APK** را باز کن و **Run workflow** را بزن.
3. پس از موفق شدن ساخت، از بخش **Artifacts** فایل **KhodroMan-debug-apk** را دانلود و ZIP را استخراج کن.
4. فایل **app-debug.apk** را روی گوشی نصب کن.

## نکات
- اطلاعات در حافظه‌ی محلی برنامه می‌ماند. پیش از حذف یا نصب مجدد برنامه، خروجی پشتیبان بگیر.
- موعدهای سرویس نمونه و قابل تنظیم‌اند؛ دفترچه‌ی راهنمای خودرو و نظر متخصص ملاک نهایی است.
- نسخه‌ی APK خروجی، debug است و برای انتشار رسمی در فروشگاه نیاز به امضای release دارد.
